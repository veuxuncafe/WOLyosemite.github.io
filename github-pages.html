用 GitHub Pages 搭建一个轻量博客

从仓库配置到页面发布，整理一套简单、稳定、适合长期维护的个人站点方案。

GitHub Pages 很适合用来搭建个人博客：仓库负责保存内容，Pages 负责发布网页，不需要额外购买服务器。

最小结构

一个静态博客只需要入口页面、样式文件和文章页面。先把内容写清楚，再逐步增加分类、搜索和评论功能，维护成本会更低。

发布前检查

确认仓库名称为 veuxuncafe.github.io，Pages 的来源设置为 main 分支根目录，然后等待 GitHub 完成部署即可。
