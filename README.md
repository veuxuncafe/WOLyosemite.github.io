# 个人博客（veuxuncafe）

简洁的中文个人博客，使用纯 HTML、CSS 和 JavaScript 构建，可直接部署到 GitHub Pages。

## 发布

将本目录中的全部文件上传到 `veuxuncafe/WOLyosemite.github.io` 仓库，并在仓库的 `Settings -> Pages` 中选择 `main` 分支和根目录。部署完成后访问：

https://veuxuncafe.github.io/WOLyosemite.github.io

## 写新文章

复制 `posts/hello-world.html`，修改标题、日期和正文，再在 `index.html` 的文章列表中添加一条链接即可。
